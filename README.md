# 🌤️ Weather API

A simple and user-friendly weather application that fetches real-time weather information using a weather API. Enter a city name to get current weather conditions such as temperature, humidity, wind speed, and more.

## ✨ Features

* 🌍 Search weather by city name
* 🌡️ Display current temperature
* 💧 Show humidity
* 💨 Display wind speed
* ☁️ Show weather conditions
* 🔄 Fetch real-time weather data from an API
* 📱 Responsive and easy-to-use interface
* ⚠️ Handles invalid city names and API errors

## 🛠️ Technologies Used

* **HTML** — Structure of the application
* **CSS** — Styling and responsive design
* **JavaScript** — Application logic and API integration
* **Weather API** — Fetching real-time weather data

## 🔑 API

This project uses a weather API to retrieve current weather information.

Typical API data may include:

```text
Temperature
Feels Like
Humidity
Wind Speed
Weather Condition
Weather Icon
Location
```

## 📸 How It Works

1. Enter the name of a city.
2. The application sends a request to the weather API.
3. The API returns the current weather data.
4. JavaScript processes the response.
5. The weather information is displayed on the screen.

## ⚠️ Error Handling

The application handles common errors such as:

* Invalid city names
* Empty search input
* API request failures
* Invalid or missing API keys
* Network errors
